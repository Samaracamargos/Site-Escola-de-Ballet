# Arabesque — Escola de Ballet

Projeto inspirado no layout enviado do Figma.

## Como abrir
1. Abra a pasta no VS Code.
2. Abra o arquivo `index.html` no navegador.
3. Coloque as imagens reais da escola dentro da pasta `images/`.
4. Renomeie-as para:
   - ballet.jpg
   - sonia.jpg
   - aline.jpg
   - isabelle.jpg

## Próximos passos
Você pode substituir os textos, links do WhatsApp/Instagram e imagens pelos dados reais da escola.
